# Isometric UI & Animations Skill

This folder contains the `isometric-ui-animations` skill for Antigravity or any compatible agentic system.

## Overview

This skill teaches the AI agent how to build true 3D isometric UI components (buttons, grids, cards) and animations using **React** and **Tailwind CSS**. It relies on CSS transforms (like `rotateX` and `rotateZ`) to create orthographic projections and uses Tailwind's arbitrary shadow values to simulate depth.

## File Structure

- `SKILL.md`: The core instructions, rules, and code templates for the agent. It includes examples of using Tailwind v4 `@utility` directives and fully functional React component snippets.

## Usage

When an agent needs to create an isometric interface, strategy game UI, or 3D interactive button, it will read `SKILL.md` to ensure the correct angles, lighting, and animation patterns are applied.

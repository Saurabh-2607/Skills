# Skeuomorphic UI Skill

This folder contains the `skeuomorphic-ui` skill for Antigravity or any compatible agentic system.

## Overview

This skill teaches the AI agent how to design and implement dark skeuomorphic components with consistent lighting, material depth, and tactile motion using **Tailwind CSS**. It enforces top-down lighting and layered drop-shadows to build hyper-real components like knobs, sliders, inset tracks, and raised buttons.

## File Structure

- `SKILL.md`: The core instructions, rules, and CSS templates for the agent. Includes explicit shadow stacks for raised shells and inset surfaces.

## Usage

When an agent needs to create a realistic hardware-like interface, rotary dials, or tactile switches, it will read `SKILL.md` to ensure the correct material recipes and color palettes (`#080808` to `#1a1a1a`) are applied.
